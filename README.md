# Angular Practice

A collection of small, focused exercises for practicing Angular concepts — one task at a time, building up from fundamentals to more advanced patterns.

## Purpose

This repo is a personal sandbox for learning and reinforcing Angular by building small, self-contained implementations rather than following tutorials passively. Each task lives in its own folder (or branch) and focuses on a specific concept.

## Topics covered

- [ ] Components & templates (inputs, outputs, lifecycle hooks)
- [ ] Dependency Injection (providers, injector hierarchy, tokens)
- [ ] Routing & navigation (guards, resolvers, lazy loading)
- [ ] Reactive & template-driven forms
- [ ] RxJS & observables (state management basics)
- [ ] HTTP client & API integration
- [ ] Standalone components
- [ ] Signals
- [ ] Unit testing (Jasmine/Karma or Jest)
- [ ] State management (NgRx / signals-based store)

*(Update this list as you go — check items off or add new ones.)*

## Getting started

```bash
# clone the repo
git clone https://github.com/Fatma-Abdelhameed/Practice-Library.git
cd practice-library

# install dependencies
npm install
ng serve
```
